# AutoMatch SI 🚗

A mobile-friendly car finder for the Slovenian market with real Avto.net data.

## Quick Start (Demo mode — no install needed)

Just double-click `index.html` — it loads 20 demo cars instantly.

---

## Get Real Avto.net Data (Scraper)

### Requirements
- Node.js (https://nodejs.org) — no other packages needed!

### Run the scraper
```bash
node scraper.js
```

This will:
1. Crawl Avto.net search pages (4 categories × 5 pages = ~500 listings)
2. Parse make, model, year, price, km, fuel, owners, and more
3. Save everything to `cars.json`
4. The app auto-loads `cars.json` on refresh

**Note:** The scraper adds 1.5s delays between requests to be respectful. A full run takes ~3-4 minutes.

---

## Run with a local server (recommended for scraper data)

```bash
npm start
# then open http://localhost:3000
```

Or use VS Code's **Live Server** extension.

## How the scraper works

1. Fetches 4 car type categories from avto.net search pages
2. Parses HTML listings with regex (no dependencies needed!)
3. Adds model-based specs lookup (length, trunk size) for common models
4. Detects "Slovensko poreklo" and "1. lastnik" from listing text
5. Calculates maintenance estimates by fuel type
6. Saves deduplicated results to `cars.json`

## Extending

- Add more car categories by editing `CATEGORIES` in `scraper.js`
- Adjust scoring weights in the `scoreCar()` function in `index.html`
- Add more model specs to `MODEL_SPECS` in `scraper.js`
