AutoMatch SI 🚗

AutoMatch SI is a modern, mobile-friendly car finder built for the Slovenian market, designed to help users discover the right car through an intuitive, quiz-style experience.
The app works fully on the frontend and can optionally load real Avto.net data generated by a scraper.

How It Works

AutoMatch SI guides users through a short, progressive flow:

Vibe – What type of car fits your lifestyle?

Filters – Set realistic limits (price, year, ownership)

Budget – Define what you can actually afford

Results – Swipe through matched cars and save favorites

All logic runs in the browser. No backend is required.

Quick Start (Demo Mode)

No installation needed.

Download or clone the repository

Open the project folder

Double-click index.html

The app will instantly load 20 demo cars.

Running with a Local Server (Recommended)

A local server is recommended if you want:

Proper fetch loading (cars.json)

Sharing URLs

Mobile testing on the same network

Option 1: VS Code Live Server

Install Live Server extension

python -m http.server
# then open http://localhost:8000
Using Real Avto.net Data (Optional Scraper)

The project includes a Node.js scraper that collects real Avto.net listings and saves them locally.

Requirements

Node.js (https://nodejs.org
)

Run the scraper
node scraper.js

The scraper will:

Crawl Avto.net search pages
(4 categories × 5 pages ≈ 500 listings)

Parse:

Make & model

Year

Price

Mileage

Fuel type

Ownership count

Detect:

Slovensko poreklo

1. lastnik

Estimate annual maintenance costs

Save results to cars.json

Once generated, refresh the page and the app will automatically load the real data.

⏱️ The scraper uses ~1.5s delays between requests and takes ~3–4 minutes to complete.

How the Scraper Works

Fetches multiple Avto.net category result pages

Parses raw HTML using regex (no external dependencies)

Enriches listings with:

Model size & trunk data

Fuel-based cost estimates

Removes duplicates

Outputs clean JSON for frontend use

Customization & Extending

Add categories: edit CATEGORIES in scraper.js

Tune matching logic: adjust scoreCar() in index.html

Add car specs: extend MODEL_SPECS in scraper.js

UI tweaks: all styles are self-contained in index.html
